はじめに

このアプリだけで用語集が引けますか

Lexiconは、お手持ちの用語集を持ち歩くための道具です。用語集そのものは付属していません。 ExcelやNumbersで作った単語帳を読み込んでお使いください。
辞書データも含まれていません。PDIC形式（.dic）やEPWING形式の辞書をお持ちであれば、 追加して用語集と一緒に引けます。
なお、使い方を試すための見本の用語集（12語）はアプリの中に入っています。

用語集の入れ方

どの形式のファイルから読み込めますか

Excel・Word・Numbers・Pages から読み込めます。Excelは見出し語と訳語の列を読み取ります。
WordとPagesは、文書の中の表だけを読み取ります。2列以上の表が用語集とみなされ、 前後の本文や、見出しを入れただけの1列の枠は取り込みません。中身のない列も落とします。 本番用にWordであんちょこを作っている方は、その表をそのまま入れられます。
1つのファイルに表が複数あれば、「表1」「表2」と切り替えて選べます。列の並びが表によって違っても、 「見出し語と訳語を入れ替える」で1タップで直せます。PDFからは読み込めません。

要る語だけを選んで入れられますか

できます。読み込み画面の「語を選んで読み込む」にチェックを入れると、行ごとにチェックが出ます。 要らない行を外して読み込んでください。ボタンに入る語数が出ます。

持っているExcelの単語帳は、どれを入れればよいですか

全部入れてしまって大丈夫です。案件ごとのファイルは、案件名を付けたまま読み込んでください （「〇〇会議」など）。これまでの単語帳を1つに合算したファイルがあれば、案件名を付けずに読み込むと 「共通」に入り、どの案件を選んでいても一緒に引けるようになります。

「すべて」と「共通」は、どう違いますか

  • すべて：用語集の全部の語を横断して引きます。ふだんはこれで使います。
  • 案件名：その案件の語と、案件を付けていない語だけに絞ります。本番前の準備に向いています。
  • 共通：案件を付けていない語だけ。分野の定訳など、どの仕事でも使う語の置き場所です。

「共通」は「全部入り」という意味ではなく、「案件なし」の語のことです。

どの案件に入れたか分からなくなりませんか

「すべて」で引けば、どこに入っていても見つかります。検索結果には案件名が小さく表示されるので、 引いたあとに出どころも分かります。

使い方の例

よく使う案件を10件ほど入れておき、これまでに作ってきた単語帳は1つに合算して「共通」に入れておく。 ふだんは「すべて」で横断して引き、本番前の準備のときだけ案件を選ぶ。

何語まで入れられますか

上限はありません。7万語で試して、1文字あたりの検索は0.02秒前後でした。 通常の使い方で重くなることはありません。

検索結果が「300+」で止まります

画面に出すのは300件までです。1文字や2文字で引くと数千件が当たるため、そこで打ち切っています。 もう1文字足すか、「完全一致」に切り替えてください。
案件を選んでいる間は、その案件の語を先に確保してから共通の語を入れるので、 共通に数万語あっても、案件の語が押し出されることはありません。

元のExcelファイルは消してもよいですか

消さずに保管してください。アプリは「本番で引くための場所」で、原本はお手元のExcelです。 端末を替えるときや、用語集を同僚と共有するときに必要になります。 アプリの中で足した語も、「Excelで書き出す」でいつでも取り出せます。

表示と読みやすさ

文字が大きすぎる／小さすぎる

画面右下の「A A」で、8段階に変えられます。iPhoneで一覧を多く見たいときは、小さいほうへ。

読み仮名がカタカナで読みづらい

「⚙︎ 設定」の「表示」にある「読み仮名をひらがなで表示」を入れると、表示のときだけひらがなになります。 用語集の中身は変わりません。

見出し語のうしろに読み仮名がくっついている

古い辞書ソフトから書き出したExcelに多い形です（「人口爆弾ジンコウバクダン」など）。 「用語集と辞書」→「その他」→「見出し語の末尾の読みを切り出す」で、見出し語と読みに分けられます。 一覧から、分けてよい語にチェックを入れて実行してください。読みは「カタカナのまま」か「ひらがなに直す」かを選べます。 実行前に「Excelで書き出す」で控えを取っておくと安心です。

書き出し（控えを取る・人に渡す）

Excel・Word・CSVに書き出すには

「用語集と辞書」で範囲（「すべて」や案件）を選び、「Excelで書き出す」または「Wordで書き出す」を押します。 CSVは「その他」の中にあります。
押すと「〇〇を用意しました」と出て、その下に「iCloud Driveなどに保存する」ボタンが現れます。 そのボタンから、「“ファイル”に保存」で保存するか、AirDropやメールで人に渡せます。 ファイルを作ってから押す形にしているのは、iOSの共有画面が押した直後しか開けないためです。

どの形式を使えばよいですか

  • Excel：控えを取るとき、直してまた読み込むとき。見出し行がそのまま列名になります。
  • Word：本番に持ち込むあんちょこを作るとき。見出し語と訳語の2列の表になります。印刷しても、WordやPagesで手直ししてもかまいません。直したものは、また読み込めます。
  • CSV：Windows版PDICに取り込むとき。UTF-16で書き出します。

PDICに取り込むときは、「辞書設定＜詳細＞ → 辞書変換」で、変換元ファイル形式を「CSV形式」にしてください。 「PDICテキスト形式」のままだと、1語しか取り込まれません。

辞書（PDIC・EPWING）

大きなEPWING辞書が開けません

zipのまま開こうとすると、辞書によっては数百MBを取り出すことになり、途中で止まることがあります。 その場合は、zipではなくフォルダの中のファイルを直接選んでください。 CATALOGS（辞書フォルダの一番上）と HONMON（DATAフォルダの中）の2つを選べば、展開せずにそのまま開けます。 大きな辞書でも、必要な部分だけを読むので速く開きます。

開けない辞書があります

次の形式には、まだ対応していません。

  • .ebz（EBZIPで圧縮された辞書。ファイル名の末尾が .ebz のもの）
  • 電子ブック（EB）形式（本文が START というファイルのもの）

これらはEBPocketなどでお使いください。EPWING形式（CATALOGS と DATA/HONMON があるもの）と PDIC形式（.dic）は、そのまま開けます。

辞書が0語と表示されます

iCloudのダウンロードが終わっていないことが多いです。ファイルアプリでその辞書を開き、 雲のマークを押して実体をダウンロードしてから、選び直してください。

アプリの更新

新しいビルドに更新すると、用語集は消えますか

消えません。更新しても、用語集・辞書・設定はそのまま残ります。同期ファイルにも影響しません。
ただし、アプリを削除して入れ直すと、中の用語集は消えます。削除する予定があるときは、 先に「Excelで書き出す」で控えを取るか、同期を設定しておいてください。

ChatGPTと外部検索

ChatGPTで調べたあと、アプリにどう戻りますか

ChatGPTはこのアプリの外で開きます。画面を下から上にはらう（またはホームボタン）でLexiconに戻ると、 元の続きから使えます。語を登録しないまま戻ってかまいません。

アプリの中で答えを出せますか

「⚙︎ 設定」の「外部検索」にOpenAIのAPIキーを入れると、アプリを離れずに答えが出ます。キーはその端末にだけ保存されます。

同期とバックアップ

iPadとiPhoneで同じ用語集を使うには

「用語集と辞書」の「同期する」で、iCloud Driveの1つのファイルに保存します。 最初だけ、1台目で「同期ファイルを新しく作る」、2台目で「選ぶ」を行ってください。 以後は「同期する」を押すだけです。どちらの端末の語も消えません。

1台でしか使いませんが、同期は必要ですか

必要ありません。ただし作っておくと、機種変更やアプリの入れ直しのときの控えになります。

Questions and answers

Lexicon for Interpreters — last updated 26 September 2026

Before anything else

Does the app come with a glossary?

No. Lexicon is a tool for carrying your own glossaries: import the word lists you have made in Excel or Numbers.
No dictionary data is included either. If you own PDIC (.dic) or EPWING dictionaries, you can add them and search them together with your glossary.
A twelve-term sample glossary is built into the app so you can try it out.

Getting your glossary in

Which file formats can be imported?

Excel, Word, Numbers and Pages. Excel gives it a column of headwords and a column of translations.
From Word and Pages it reads the tables only. A table of two or more columns is taken as a glossary; the prose around it, and a one-column box holding nothing but a heading, are left out, as are columns with nothing in them. If you keep your booth cheat sheet as a Word table, it goes straight in.
Several tables in one file appear as “Table 1”, “Table 2” and so on. If the languages sit in a different order from one table to the next, “Swap headword and translation” fixes it in one tap. PDFs cannot be imported.

Can I import only some of the terms?

Yes. Tick “Choose which terms to import” on the import screen and every row gets a tick box. Untick what you don't want; the button shows how many terms will go in.

Which of my Excel glossaries should I import?

All of them. Import each assignment's file with its own assignment name. If you keep one large file combining everything you have collected over the years, import it without an assignment name: it then lands in “Shared” and is searched whichever assignment you have chosen.

What is the difference between “All” and “Shared”?

  • All: searches every term in your glossary. This is the everyday setting.
  • An assignment: narrows the search to that assignment's terms plus the terms with no assignment.
  • Shared: the terms with no assignment — standard renderings you use on every job.

“Shared” does not mean “everything”; it means “no assignment”.

Won't I lose track of which assignment a term is in?

With “All” chosen, a term is found wherever it lives, and each result shows its assignment name, so you can see where it came from.

How many terms can it hold?

There is no limit. Tested with 70,000 terms, each keystroke took about two hundredths of a second.

The result list stops at “300+”

Three hundred results are shown at a time. One or two letters can match several thousand terms, so the list stops there. Type another letter, or switch to “Exact”.
While an assignment is chosen, its terms are taken first and the shared terms fill what is left, so a shared glossary of tens of thousands never crowds the assignment out.

Can I delete my original Excel files?

Please keep them. The app is where you look things up; your Excel files are the originals you will need for a new device, or to share a glossary with a colleague. Anything you add in the app can be taken out again with “Export to Excel”.

Reading the screen

The text is too large or too small

The “A A” buttons at the bottom right step through eight sizes. Choose a smaller one to see more terms at once on an iPhone.

Kana readings are in katakana and hard to read

Turn on “Show kana readings in hiragana” under Settings → Display. Only the display changes; your glossary is untouched.

The reading is stuck onto the end of the headword

Older dictionary software often exported glossaries this way. Open “Glossary & dictionaries” → “More” → “Split a reading off the end of headwords”, tick the terms to split, and run it. The reading can be kept in katakana or converted to hiragana. Take a copy with “Export to Excel” first.

Exporting

How do I export to Excel, Word or CSV?

In “Glossary & dictionaries”, choose what to export (All, or one assignment) and tap “Export to Excel” or “Export to Word”. The CSV export is under “More”.
The file is built first, and a “Save to iCloud Drive” button appears below. That button opens the share sheet, where you can save the file or send it by AirDrop or email. It works this way because iOS only opens the share sheet on a tap of its own.

Which format should I use?

  • Excel: for a copy you may edit and import again. The header row becomes the column names.
  • Word: for the cheat sheet you take into the booth — a two-column table of headwords and translations. Print it, or edit it in Word or Pages; an edited file can be imported again.
  • CSV: to import into PDIC on Windows. Written in UTF-16.

In PDIC, use “Dictionary settings (advanced) → Convert dictionary” and set the source file format to CSV. Left as “PDIC text format”, only one entry is imported.

Dictionaries (PDIC and EPWING)

A large EPWING dictionary will not open

Opening it as a zip can mean extracting several hundred megabytes, which may stall. Instead of the zip, choose the files in the folder directly: CATALOGS (at the top of the dictionary folder) and HONMON (inside the DATA folder). Nothing is extracted, and even a large dictionary opens at once, as only the parts being read are fetched.

Some dictionaries cannot be opened

These formats are not supported yet:

  • .ebz — dictionaries compressed with EBZIP (file names ending in .ebz)
  • Electronic Book (EB) format — where the text file is called START

Please use an app such as EBPocket for those. EPWING dictionaries (with CATALOGS and DATA/HONMON) and PDIC dictionaries (.dic) open as they are.

A dictionary shows 0 entries

Usually the file has not finished downloading from iCloud. Open it in the Files app, tap the cloud icon to download it, then choose it again.

Updates

Does updating to a new build erase my glossary?

No. Your glossary, dictionaries and settings survive an update, and the sync file is unaffected.
Deleting the app does erase the glossary inside it, so take a copy with “Export to Excel”, or set up Sync, before you delete it.

ChatGPT and external lookups

How do I get back to the app after looking a term up in ChatGPT?

ChatGPT opens outside the app. Swipe up from the bottom of the screen (or press the Home button) to come back to Lexicon, which is still where you left it. You do not have to save the term.

Can the answer appear inside the app?

Yes, if you put an OpenAI API key under Settings → External search. The key is kept on that device only.

Sync and backup

How do I use the same glossary on an iPad and an iPhone?

Use Sync in “Glossary & dictionaries”, which keeps one file in your iCloud Drive. The first device creates the file; the second one chooses it. After that, all you press is Sync, and no device loses anything.

I only use one device. Do I need sync?

No, but the file makes a good backup for a new device or a reinstall.
