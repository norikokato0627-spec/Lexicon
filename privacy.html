プライバシーポリシー

Lexicon for Interpreters ／ 最終更新 2026年9月19日

収集する情報

開発者は、利用者の個人情報を一切収集しません。氏名、メールアドレス、位置情報、 端末識別子、利用状況の記録などを、開発者が受け取る仕組みはありません。 解析ツールや広告も使用していません。

利用者が入力したデータ

用語集、案件名、案件の背景、読み込んだ辞書ファイルは、利用者の端末内に保存されます。 開発者がこれらを閲覧、取得、複製することはできません。 開発者が管理するサーバーは存在しません。

iCloudでの同期（任意）

利用者が同期を設定した場合に限り、用語集、案件名、案件の背景が、 利用者自身のiCloud Driveに置かれた1つのファイル（利用者が選んだもの）に保存されます。 このファイルは利用者のApple IDのiCloud上にあり、その扱いは利用者とApple社との契約に基づきます。 開発者がこのファイルにアクセスすることはできません。 同期はいつでもやめられます。やめてもファイルは消えないため、 不要であれば「ファイル」アプリから削除してください。

外部への通信

本アプリが外部と通信するのは、次の場合に限られます。いずれも利用者の操作によるものです。

  • 辞書に見つからない語を調べるとき。 利用者が選んだ調べる先に、次の内容が送られます。
    • ChatGPT：調べる語と、利用者が設定した質問文だけ。 利用者が設定で「案件名と背景もChatGPTに伝える」をオンにした場合に限り、 選んでいる案件の名前と、利用者が書いた案件の背景も添えられます。この設定は初期状態ではオフです。 OpenAIのAPIキーを設定していれば端末からOpenAI社のAPIに直接送信され、 設定していなければChatGPTのアプリまたはWebサイトに渡されます。
    • Google、Weblio、DeepL：調べる語だけ。
    用語集や辞書の中身は送られません。送信された内容は、各サービスの提供者の定めに従って扱われます。
  • iCloudでの同期。上記「iCloudでの同期」のとおりです。
  • 利用者が書き出したファイルを共有するとき。 利用者が選んだ送り先（AirDrop、メール、iCloud Driveなど）に送られます。
  • Web版の更新の確認。Safariで開くWeb版に限り、 配信元（GitHub Pages）にアプリ本体の新しい版があるかを確認します。 利用者に関する情報は送信しません。App Store版はこの確認を行いません。

これら以外に、本アプリが通信を行うことはありません。 機内モードでも、辞書の検索と用語集の編集は通常どおり動作します。

OpenAI APIキーについて

利用者がOpenAIのAPIキーを設定した場合、キーは利用者の端末内にのみ保存されます。 開発者に送信されることはなく、iCloudの同期ファイルにも含まれません。 キーの利用に伴う料金は、利用者とOpenAI社との契約に基づきます。

辞書データについて

本アプリには辞書データが含まれていません。利用者がご自身で用意した辞書ファイルを 読み込んで使用します。各辞書の利用条件は、その辞書の提供元の定めに従ってください。

データの削除

アプリを削除すると、端末内に保存されたデータはすべて削除されます。 アプリ内の「すべて消す」からも用語集を削除できます。 iCloudで同期している場合、iCloud Driveの同期ファイルはアプリを削除しても残ります。 「ファイル」アプリから削除してください。 開発者側に保管されているデータはないため、開発者への削除の請求は必要ありません。

お問い合わせ

本ポリシーに関するお問い合わせは、GitHub上のリポジトリ （https://github.com/norikokato0627-spec/Lexicon）よりご連絡ください。

Privacy Policy

Lexicon for Interpreters — last updated 19 September 2026

Information we collect

The developer collects no personal information whatsoever. There is no mechanism by which the developer receives names, email addresses, location, device identifiers or usage data. The app contains no analytics and no advertising.

Data you enter

Your glossary, assignment names, assignment backgrounds and any dictionary files you open are stored on your device. The developer cannot read, retrieve or copy them. The developer runs no server.

iCloud sync (optional)

Only if you turn on sync, your glossary, assignment names and assignment backgrounds are saved to a single file you choose in your own iCloud Drive. That file lives in the iCloud account of your Apple ID and is governed by your agreement with Apple. The developer has no access to it. You can stop syncing at any time; the file is not deleted when you do, so remove it in the Files app if you no longer need it.

Network use

The app contacts the network only in the following cases, each started by you:

  • Looking up a term not found in your dictionaries. The service you chose receives:
    • ChatGPT: the term and the prompt you configured, nothing else. Only if you turn on “Also tell ChatGPT the assignment name and background” in the settings are the selected assignment's name and the background you wrote for it added. That setting is off by default. With an OpenAI API key set, this goes directly from your device to the OpenAI API; without one, it is handed to the ChatGPT app or website.
    • Google, Weblio, DeepL: the term only.
    Nothing from your glossary or dictionaries is sent. What is sent is handled under each provider's own terms.
  • iCloud sync, as described above.
  • Sharing a file you exported, to the destination you choose (AirDrop, Mail, iCloud Drive and so on).
  • Update check in the web version. Only the version opened in Safari checks its host (GitHub Pages) for a newer version of itself. No information about you is sent. The App Store version does not perform this check.

The app performs no other network activity. Dictionary search and glossary editing work normally in airplane mode.

OpenAI API key

If you supply an OpenAI API key, it is stored only on your device. It is never sent to the developer and is not included in the iCloud sync file. Any charges arising from its use are governed by your agreement with OpenAI.

Dictionary data

No dictionary data is bundled with this app. You supply your own dictionary files. Please observe the licence terms of each dictionary you use.

Deleting your data

Removing the app deletes everything it stored on your device. You can also clear your glossary from within the app. If you use iCloud sync, the sync file in iCloud Drive remains after the app is removed; delete it in the Files app. As the developer holds no data, there is no need to ask the developer for deletion.
